# 可继续编辑的示例项目

正式发行包在此目录附带两份从该版本**成功的真实浏览器验收**中保存的项目：

| 文件 | 用途 |
| --- | --- |
| `kyoto-three-visits.travelstudio` | 3 张照片、2 个地点、3 次到访；查看冻结行程、照片裁切与地图快照，再继续编辑。 |
| `photo-with-unknown-facts.travelstudio` | 无 GPS、无拍摄时间的照片作品；演示未知信息保留和纯照片输出。 |

启动应用后，点击“项目与作品”，打开其中一份 `.travelstudio` 文件。示例不会代替用户自己的照片。

这些图片由测试脚本合成，采用 **CC0-1.0**；日期、位置等输入是虚构的软件测试数据，不代表真实拍摄事实。地图仍采用真实公开服务，保留各自许可与署名，见 [服务来源](../../docs/PROVIDERS.md)。项目代码采用 MIT License。

`provenance.json` 记录示例文件的 SHA-256、验收产物来源和源码提交。源码仓库保存此说明；二进制项目在发版时从成功验收产物中收集，随发行包提供。
