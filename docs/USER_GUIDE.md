# 使用说明

## 一、开始一段旅程

1. 点击「从照片开始」或「添加照片」，也可把图片拖入工作区。每批最多 50 张，支持 JPEG、PNG、WebP；浏览器无法解码的格式会明确报错。
2. 有 GPS 的照片按原始位置建立地点；没有 GPS 的照片保留为待定位，仍可制作纯照片作品。原始 EXIF 和原图不因后续编辑而改变。
3. 「添加一站」支持地址搜索、手工经纬度；地图上点选也可打开确认窗口。查看候选和精度后，再确认地点。没有填写的日期与时间保持未知。

可选 AI 地标候选位于照片地点确认窗口，需要服务端配置定位模型和单独授权。它只提出候选，必须再次核对和确认。

## 二、选择照片与到访顺序

照片、地点和到访是不同对象。同一地点上午、晚上分别到访会保留两条记录，A → B → A 不会合并为 A → B。

「全部照片」逐张勾选；搜索只筛选可见列表。「自动选择规则」可组合固定参考日期和固定参考位置半径，选择同时满足或满足任一。手工加入和排除在规则变化后仍保留。

「行程序列」可按记录时间排序，也可用上下按钮或拖动排列。绝对时间只使用有可靠时区偏移的记录；仅日期、无时间或不确定时区的记录会进入待排序区，可以手动排入。行程线表达访问顺序，不代表道路导航。

资料修正、到访合并或拆分不会自动重写已保存作品；作品保存独立的行程和资料快照。

## 三、编辑作品

点击「创作这段旅程」。右侧选择版式、艺术风格、配色、可见元素、文字和排版方式。六个家族分别为照片地图卡、撕纸双联、城市旅签、路线海报、时间胶片、旅行拼贴，各有两个结构。

在作品上选择照片、地图或文字，可拖动或通过数值输入调整位置、尺寸和旋转。Shift 点选多个元素；方向键微调，Shift + 方向键加速。画布空白区可以拖动浏览，触屏双指或 Ctrl/Command + 滚轮缩放。底栏百分比恢复适配视图。

| 模式／约束 | 行为 |
| --- | --- |
| 自动 | 内容变化后重新排版；手动拖动会转为辅助模式 |
| 辅助 | 保留已固定的位置、尺寸与裁切，整理其他内容 |
| 自由 | 保留明确位置；需要时主动整理 |
| 固定位置 | 换风格或重排时保留对象位置 |
| 固定尺寸 | 保留对象宽高，独立于位置 |
| 固定裁切 | 保留照片内部焦点、缩放与旋转 |

隐藏不会删除素材。发生空间冲突时保留上一份有效稿，可取消修改或明确释放锁定后应用。底栏的版式／风格／排版按钮，以及手机顶部的行程／属性按钮均可直接打开控制面板。

选择地图对象后点击「调整地图取景」。这里保存的是作品自己的固定视角，旅行地图中的浏览、缩放和新资料不会改变它。地图框位置和相机视角分别编辑。

## 四、照片处理与 AI

照片对象支持原图和本地艺术处理，曝光、对比、饱和度、效果强度及内部裁切均可回退。换风格保留独立锁定；本地处理不上传图片。

AI 艺术化为可选能力。授权窗口列出当前服务、选定照片和用途，仅发送移除 EXIF 的 1536 像素代理图。输出保存为独立版本，原图保持不变。若生成期间目标作品发生变化，旧结果留在衍生版本列表供手动选用。

## 五、导出图片

「导出」先生成真实文件，再展示文件预览。确认预览后下载；也可下载渲染回执。

- **展示分享**：1920、2048 或 4096 像素长边；PNG／WebP 支持透明背景，JPEG 使用明确底色。纸边、孔眼、绳结和展示阴影按当前版式输出。
- **平面印刷**：输入毫米、72–600 PPI 和 0–20 mm 出血；保持作品比例，输出 sRGB 栅格文件和物理密度信息。展示阴影与绳结不进入印刷版。上限仍为 4096 像素长边。
- **保存的地图快照**：离线时可明确选用；只有取景、风格、路线和逻辑视口一致，且快照像素足够时才可导出。缺失、过期或像素不足会报错。

地图、照片和字体必须完成准备。必需来源署名会保留。公共服务故障会显示可重试错误，未加载底图不会被当作成功作品。

## 六、保存与恢复

浏览器会自动保存当前项目。独立备份需在「项目与作品」下载 `.travelstudio` 文件：

| 文件类型 | 包含内容 |
| --- | --- |
| 完整项目包 | 项目内照片、到访、地点、作品，以及所需原图和衍生资源 |
| 当前作品包 | 当前作品冻结的资料及关联资源；不附带其他作品和无关位置 |

打开项目文件会核对路径、结构、SHA-256 和资源引用。与本机同名同 ID 但内容不同的备份会作为恢复副本打开，避免覆盖较新项目。较新且当前版本不兼容的格式保留原文件，并提供可用的只读预览。

保存的完整预览与许可允许的地图快照可用于查看旧作品；项目包不包含整片在线地图瓦片。清除浏览器数据、变更地址／端口或换设备前，请先下载备份。项目包包含精确位置与原图，向他人分享时请自行选择范围。

## 七、扩展与故障处理

「偏好设置 → 声明式扩展」导入仓库 `examples/extensions/` 中的 JSON。风格、模板和地图来源经过字段、版本和能力校验；项目内不会执行扩展脚本。作品嵌入使用中的确切配方版本。

界面可切换标准、轻量和减少透明度材质。遇到内存或网络问题，可降低导出尺寸、回到 2D，或明确使用有效地图快照。任务面板提供阶段、取消与错误；保存失败时保留当前页面并下载项目，避免先清理数据。

具体测试证据、已验证平台及尚未验证的真机性能目标见 [ACCEPTANCE.md](ACCEPTANCE.md)。
