# Travel Studio implementation

Specification: Travel Studio Complete Plan v3.0, 13 November 2026 (53 pages, supplied by repository owner).

## Authorized delivery

Build the local-first React/TypeScript application, commit progress incrementally, verify the implementation and publish a versioned release. This repository started empty.

## Scope

- Shared accessible glass workspace, parametric continuous corners and reduced effects.
- Local photo import and metadata, explicit geographic evidence, independent places/photos/visits, repeat visits and truthful time handling.
- Visible selection, anchored date/radius predicates, manual exceptions, deterministic order and explicit route gaps.
- Real MapLibre 2D/3D, DEM and building extrusion, replaceable providers, isolated atlas and artwork cameras.
- Six template families / twelve variants, six art styles / two palettes each, reversible visibility and constrained automatic/assisted/free layout.
- Nondestructive local image processing and explicitly authorized optional AI.
- Frozen export transactions, PNG/JPEG/WebP, real 4096px rendering, presentation/flat-print outputs and attribution.
- IndexedDB recovery, full/lean project packages, asset integrity, undo/redo, cancellation and stale-task protection.
- Twelve bounded modules, public contracts, declarative extension validation and example extensions.

## Delivery gates

A-Q acceptance from the source plan covers import, search, terrain, style, multi-photo composition, export, recovery, absence of keys, privacy, selection/order, layout constraints, unified UI and extension boundaries. Automated tests and browser evidence must distinguish verified behavior, network failures and unverified device-specific targets. Performance numbers in the plan are targets until measured. Do not describe a mock map, CSS tilt or enlarged low-resolution screenshot as a verified map/3D/export capability.

Progress and exact validation evidence will be maintained in docs/ACCEPTANCE.md. Implementation commits are checkpoints; release gates run against the final commit.
